# DSA5206 project presentation

[Download the editable PowerPoint](DSA5206_Full_Project_Presentation.pptx)

This presentation brings together the paper review, reproduction assessment, classroom checklist and expanded experiments. It uses the supplied NUS presentation's visual style, with layouts adapted to the evidence on each slide.

- 39 slides: 27 main slides and 12 appendix slides.
- English slide text with Chinese speaker notes and source references.
- Editable charts and tables; chart data are embedded in the PowerPoint.
- Covers all 36 experimental configurations, the 12 classroom checklist questions, data provenance and missingness, the initial Ridge failure and its repairs, modern encoders, patient-grouped model selection, paired comparisons and fivefold sensitivity analysis.

The main results distinguish the published paper, the original-method rerun, bounded OLS controls, the best observed modern configurations and training-only model selection. The improvement figures are exploratory results on the same 94 images from 65 patients, rather than an independent external validation. The appendix retains unsuccessful configurations and full comparisons.

The original paper and group reproduction figures are attributed in the speaker notes. The supplied source template and course PDFs are not redistributed. Full-precision experiment outputs remain in `results/`; chart source values in this presentation are rounded to six decimal places.

For a shorter talk, use the main slides and consult the appendix for questions about parameters, complete results, data versions and reproducibility. Adjust the slide selection to the allotted speaking time.
